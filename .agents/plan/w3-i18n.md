# W3: choosing the reader's language

`aproxy` and `aproxy-format` distinguish a terminal **reader** from a machine or forensic **writer**. The English in a machine document is the English rendering of the same reason, not a second summary. Keep public fields, codes, details, exit status, line order and stream assignments independent of language. The desktop web UI has a separate catalog.

## Add or change wording

- Put a `message!` in the owning area's `src/i18n/` module (`aproxy-ipc` owns the macro, shared parser/IPC reasons and locale resolution). Give the function a meaningful name and typed, named parameters. Define `en:` and `zh:` together. Use `en_one:` and `en_other:` for a count; zero uses the plural. Every arm must use precisely the declared parameters. Plain messages return a static string; parameterized messages format only the selected arm.
- At a terminal sink use `current()`. Pass `Lang` explicitly through a renderer used by multiple audiences. At a protocol, persistence or logging boundary use `Lang::En`, including a role process's own stderr. If a later process needs a different language, carry the classification and safe data, not a sentence to be parsed. Never use a translated string as a discriminator. Third-party/OS evidence and existing log contents are not translated.
- For a public code, reuse its code and sanitized details. New private local reason variants are not wire codes. Only the private startup result, `install/state.json` (`error_render`), and `install/last-exit.json` (`code`, `render`) support extra rendering evidence. Persist only the allowlisted rendering fields for a recognized refusal; do not copy a peer’s details object. Discard control characters from terminal evidence. Reconcile every stored precheck reason with its own public diagnostic; keep the first underlying cause in the English summary. A startup report is optional, limited to 32 KiB and 20 nonempty rendered lines, and must match a complete, unique block in the excerpt. If the evidence is unrecognized, truncated, inconsistent or not present, display the original evidence. Do not guess an OS error, retry count, private header or arbitrary configuration value to improve the prose.
- Help localizes authored descriptions and headings, not command syntax, clap's annotations/parse errors or the final English agent hint on `aproxy` commands. `aproxy-format` has no agent footer. Format `init` localizes editable TOML comments, not keys or values. The hidden package verifier, `--version`, worker protocol and log replay remain separate from terminal notices. `install --force` is not localized: its frozen implementation and shared helper output must remain interoperable indefinitely. A child's ordinary `restore` output can be forwarded without the parent interpreting it.

## Resolve once, test both audiences

Both terminal programs first try `APROXY_LANG`, then the `language` field in `settings.json`, then the system UI language, then English. Empty (including whitespace-only) and non-Unicode environment values count as absent; `APROXY_LANG=system` also falls through. In the environment a case-insensitive `zh` prefix selects Chinese; all other explicit tags select English. Read only a regular settings file, at most 256 KiB, without creating the home or waiting for a FIFO. Only `en` and `zh-CN` override the system in settings; malformed/unrecognized settings do not prevent resolution or suppress validation. Windows uses the first user-preferred UI language, not regional formatting; Unix tries `LC_ALL`, `LC_MESSAGES`, `LANG`. The early `--version` path does not read a home. The frozen force route skips the settings read. `__serve`, `__watchdog`, `restore-at-login`, `install --continue`, `skill __verify-package` and format role processes skip terminal initialization entirely, including preflight. Asking for help is a terminal operation. A plain terminal failure formats only its reader’s language. The IPC crate's existing dependencies suffice even without client features.

Start CLI integration children in `tests/common::TestHome` (English by default). Compare a complete document in both languages where it is deterministic; otherwise compare its fields and normalize only independently generated identities, time, or locations. Cover stderr and exit status too. `tests/worker_language.rs` separates machine/reader language; `python tests/startup_compat.py` builds and exercises both real startup readers against the other writer; `tests/cli_tree.rs` walks help against the original ordered option fixture. The macro has compile-fail doctests. `python tests/i18n_origins.py` checks Chinese originals in both directions (`--inventory` lists baseline locations and exceptions); the allowlist is for messages that had no Chinese, not permission to change old wording.
